# Agent Instructions

## Project

This is a Vite and TypeScript browser game.

## Commands

- Install dependencies: `npm install`
- Run locally: `npm run dev`
- Validate changes: `npm run build`
- Preview production build: `npm run preview`

## Guidance

- Keep changes small and focused.
- Match the existing TypeScript and DOM-rendering style.
- Do not commit generated folders such as `node_modules`, `dist`, or `dev-dist`.
- Run `npm run build` after code changes when possible.
